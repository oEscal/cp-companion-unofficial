First v1.0.0 release of CP Companion, an unofficial Android companion for train journeys in Portugal.

### Features
- View CP station departures and arrivals, train details, calling points, and journey status.
- Add journeys manually, import details through paste/share, or opt in to SMS import and ticket-notification detection.
- Automatically track validated upcoming journeys about an hour before departure. The ongoing notification shows delays, platform information, and time remaining, and alerts you when it is time to leave the train.
- Store ticket details locally with encrypted storage. Includes English and Portuguese, plus light and dark themes.

### Install
Requires Android 11 or newer.

- **Obtainium:** [Add CP Companion](https://apps.obtainium.imranr.dev/redirect?r=obtainium://add/https://github.com/oEscal/my-cp-companion)
- **Manual install:** Download `cp-companion.apk` and `SHA256SUMS` from the release assets and verify the APK checksum before installing.

The release also includes the source archive and signing certificate. Install updates over the existing release to preserve saved journeys; updates must use the same signing certificate.

### Please note
CP Companion is unofficial and is not endorsed by CP. Imported journey details are not a valid ticket, so keep your ticket for travel. Live data and automatic background tracking may be delayed or unavailable.
